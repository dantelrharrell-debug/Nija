- Confirmed Kraken exit P&L matches a **unique** open ledger position only when its recorded OPEN transaction was also authenticated from the same account, order ID, direction, symbol, size, entry fee and price. Legacy manual/ambiguous OPEN entries remain pending, not profitable or losing trades.
- Closing a position now reserves an SQLite write transaction, validates exact position ownership/symbol and finite exit economics, refuses an order-ID replay against a different position, and cannot overwrite an already completed historical trade. Concurrent/same-account duplicate order attempts fail closed.
- Per-instance storage evidence differentiates a root overlay from a dedicated mount. The result **never falsely attests** to backup, migration, historical completeness or recovery, and performance reports disclose pending unmatched closes plus unverified ledger durability.
